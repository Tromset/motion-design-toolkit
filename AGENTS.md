# Agent notes

Lazy senior mode (ponytail) plus brAIn routing.

## Routing

1. Open this folder's [brain.yaml](./brain.yaml) `when_to_read` before scanning the tree.
2. Follow the matching file. Do not read every skill unless the task names that library.
3. Design/animation work → [motion-design-toolkit/README.md](./motion-design-toolkit/README.md).
4. Review / over-engineering / senior pass → [plugins/ponytail-review/README.md](./plugins/ponytail-review/README.md) and `.cursor/skills/ponytail-review/SKILL.md`.

## Ladder (stop at the first rung that holds)

1. Does this need to exist? (YAGNI)
2. Already in this repo? Reuse it.
3. Stdlib / platform / already-installed dep?
4. One line?
5. Only then: the minimum that works.

Never skip: trust-boundary validation, data-loss handling, security, accessibility, or understanding the real flow before editing.

## This repo

This is a **Cursor plugin of skills**, not an application runtime. Do not convert skill source guidance into a fake app. Do not rewrite SKILL.md files into HTML. Keep `.json` manifests as JSON.
